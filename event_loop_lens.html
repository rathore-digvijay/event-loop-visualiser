Time is simulated: the clock jumps straight to the next timer or I/O completion. Called from the main script, setTimeout(fn, 0) vs setImmediate(fn) order is not guaranteed in real Node: it depends on whether 1ms has passed when the loop starts. By default this tool models a fast start (setImmediate first); tick Script took ≥ 1ms to see the other ordering.
